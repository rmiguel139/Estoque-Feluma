README - Sistema de Gerenciamento de Estoque

Descrição

Este projeto é um sistema de gerenciamento de estoque para controle de patrimônios. Ele permite a entrada, organização e filtragem de patrimônios de acordo com diversos critérios, como setor, modelo e tipo. Também valida o setor de destino dos patrimônios registrados, garantindo um melhor controle do inventário.

Tecnologias Utilizadas

Front-end

React

JavaScript

HTML

CSS

Back-end

Node.js

MySQL

Funcionalidades

Cadastro de patrimônios: Registro de novos patrimônios no sistema.

Filtragem: Possibilidade de filtrar patrimônios por setor, modelo e tipo.

Rastreamento de destinação: Validação do setor para onde cada patrimônio foi enviado.

Banco de dados MySQL: Armazenamento seguro e organizado dos dados.
